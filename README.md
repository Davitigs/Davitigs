# Hi, I'm Davit

I'm a senior full-stack engineer working with TypeScript, Angular, NestJS, PostgreSQL, Prisma, BullMQ, and Docker. I'm also building projects with C# and ASP.NET Core to extend my backend skill set.

My background also includes volcanology and geospatial analysis: DEM-based volcanic volume calculations, ArcGIS Pro, GDAL, GMT, and Python. That experience informs my interest in mapping and scientific-data applications.

- **[Field Station](https://github.com/Davitigs/usgs-seismic-dashboard-react)** — a USGS earthquake dashboard exploring React, TypeScript, server-state caching, UI state, and data visualization.
- **[HabitTracker](https://github.com/Davitigs/habitTracker)** — a focused ASP.NET Core and Angular application exploring persistence, validation, habit statistics, and automated testing.

My repositories include both current portfolio projects and earlier learning exercises. The projects above are the best starting point for reviewing my work.
